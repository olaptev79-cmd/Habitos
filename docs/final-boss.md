# HabitOS final boss pack

## Added in this pack
- Habit deletion flow
- Settings profile update endpoint and UI
- Admin tab scaffold in frontend
- Migration runner script
- Smoke test script scaffold
- Final boss PowerShell starter script

## Recommended order
1. backend: npm install
2. backend: npm run migrate
3. backend: npm run seed
4. backend: npm test
5. backend: npm run smoke
6. backend: npm start
7. frontend: npm install && npm run dev
